# Phase 7 · RA 分析状态与科学结论

**RA-0 因睡眠和重放时标缺失受阻。** 四只鸟的文件包含双侧 RA 排序脉冲，公开版无法确定每只鸟的可用睡眠区间。RA-1 至 RA-4 尚未执行，因此现有项目没有 RA 的 d₂、左右半球效应或重放关联结果。[数据可行性](07_ra_feasibility.md)

| 证据层级 | 当前结论 |
|---|---|
| 成功复现 | 小鼠 13 个会话均呈 Wake d₂ 低于 NREM，原 MATLAB 合成验证已通过。 |
| 探索性观察 | 两只斑胸草雀的 LMAN 宽口径诊断依参照状态变化；SWS 残差重尾，严格跨态比较缺少足够合格单元。 |
| 技术限制 | RA 缺少对齐的状态与重放标注，三个爬行动物候选均未达到现有的连续排序脉冲与睡眠元数据要求。 |
| 演化解释 | 这些结果不足以推断鸟类与爬行动物存在保守的状态依赖临界性，也不足以解释鸟类 RA 与 LMAN 的生理临界性差异。 |

## 获得时间元数据后的验证顺序

1. **RA-1**。先选择元数据完整的一只鸟核验时基、连续片段、左右索引、重复脉冲和单元隔离。以手工分群标签和可查的违例、漂移指标评估单元质量。记录后在其余鸟逐项复核。符合条件的源文件及中间数据留在项目 Drive，用 Colab 按 40 ms 分箱生成可验证的小型输入。
2. **RA-2**。在 GitHub Actions MATLAB R2024b 中运行已固定的 Sooter 估计器。按每鸟每侧的睡眠有效片段拟合 AR(5)，β=2，Yule–Walker。先检查收敛、近似稳定性、残差自相关和重尾，再报告 d₂、发放率、Fano、静默箱比例及模型系数。两侧保留共享时段的配对记录。
3. **RA-3**。优先对齐作者重放标签。若获得完整模板输入，先在公开示例核对事件时点和两侧定义，再进行检测。保留可用事件与覆盖率。将重放频率、占时率及群体爆发量分别保存。
4. **RA-4**。在同一鸟、半球和睡眠录制内用固定时长的连续窗分析。先以 60 秒窗检查估计稳定性，再用预定的重放密度分位数定组。按发放率、爆发、时间及有效单元数检查共同支持。依据时间块做录制内不确定性估计，以鸟汇总跨记录一致性。检测左右 d₂ 差与两侧爆发或重放不对称的关系。单元数、单元质量、发放率、箱宽、AR 时间跨度和等时长结果逐项保存。若核验过的鸣唱窗与睡眠窗充分，仅作第二层行为对照。
