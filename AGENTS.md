On a mounted Colab runtime use `/content/drive/MyDrive/Research/Criticality_Evolution/results_archive/run_logs/<study>/<run>`. Use local `logs/` for temporary staging. Record the Drive file reference and SHA-256 after each run, and verify the remote copy before removing local originals.
- Validate external inputs and prerequisites once at the entry point. Rely on established invariants downstream, surface unexpected errors with diagnostics, and add retries or recovery for known failure modes. Enforce scientific QC and protect data integrity.
